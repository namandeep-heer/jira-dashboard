Proxy status

This app uses a local Node.js proxy to talk to Jira (avoids browser CORS restrictions).
The proxy must be running before you can fetch data.

Checking proxy…
To start the proxy, open a terminal in the jira-dashboard folder and run:
node proxy.js

Jira credentials

Stored in the local dashboard account on this machine. The proxy forwards requests to your Jira using Basic Auth.

Jira base URL is managed by the proxy configuration. Enter only the Jira email and API token here.

Sync selected market releases and projects from Jira. A project is queried only when that market release is enabled on it, using its include mode (market, patches, or both). Scheduled sync runs while this dashboard is open.

Developer Velocity

Track whether developers are behind schedule, on track, or have capacity for more work based on estimated vs actual time. Market-release projects only — Quality is under Quality Insights.

Data Gaps

Find tickets missing dev estimate days, and dev-done tickets missing actual days. Market-release projects only — Quality is under Quality Insights.

Analytics

Status, priority, and issue-type breakdowns for market-release projects. Quality (bugs/support) is under Quality Insights.

Release Report

Company-ready briefing for market-release delivery — progress, high-value features, and freeze/GA risks. Quality (bugs and support) has its own package under Quality Insights. Export as PowerPoint plus an HTML list of every ticket.

Quality Insights

Open defect and support risk for the selected market release and its patches — readiness, queue, and per-patch load. Feature delivery stays under Insights.

Quality Phase

Open quality queue over time: Product → Dev, bounces to Rejected/Replied, and rework back to Dev. Snapshots are the current open cohort (Open Bugs does not include QA or closed tickets).

Quality Progress

Status movements in the open quality queue (bugs/support still not in QA or closed). Forward, bounce, and rework over time.

Team View

Tickets grouped by developer across market-release projects. Quality is under Quality Insights.
